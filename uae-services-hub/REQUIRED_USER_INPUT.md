# مطلوب منك (REQUIRED_USER_INPUT)

كل ما دونه يمكن إكماله بدون هذه المعلومات، لكن هذي الأشياء ما أقدر أستنتجها. المشروع بُني بحيث كل بند هنا **طبقة قابلة للربط لاحقًا** دون إعادة هيكلة.

## 1. حاسم قبل الإنتاج

| # | المطلوب | لماذا | الوضع الحالي |
|---|---|---|---|
| 1 | **اسم النطاق** | Caddy + SSL + Canonical URLs + Open Graph | `APP_URL` في `.env.example` = `http://localhost:3000` |
| 2 | **مزود SMS** (Unifonic / Twilio / Etisalat) | OTP — الطبقة جاهزة (`lib/otp/provider.ts`) لكن بلا مزود ما يشتغل التحقق بالجوال فعليًا | يعمل بوضع "console" (يطبع الكود بدل الإرسال) |
| 3 | **مزود الدفع** (Telr / Network International / Checkout.com / Stripe) | Telr و NI الأقرب للإمارات؛ Stripe يحتاج كيان مسجّل | لا شيء مربوط — لا مفاتيح وهمية بالكود، والاشتراكات المدفوعة معطّلة |
| 4 | **مزود الذكاء الاصطناعي** | Anthropic API؟ أو Ollama محلي؟ يؤثر على تصميم streaming والحدود | طبقة abstraction مُخطَّطة (المرحلة 5)، لم تُبنَ بعد |
| 5 | **SMTP** | إشعارات البريد | لا مزود مربوط، الإشعارات داخل الموقع فقط تعمل حاليًا |

## 2. قانوني — لا أقدر أخترعه

| # | المطلوب |
|---|---|
| 6 | نص **الشروط والأحكام** وسياسة الخصوصية وسياسة الاسترداد/الإلغاء — يجب مراجعة محامٍ إماراتي، وخصوصًا التوافق مع قانون حماية البيانات الشخصية الاتحادي (PDPL) |
| 7 | هل ستطلب **رقم تصريح إعلان عقاري** (Trakheesi/DARI)؟ الحقل موجود بالمخطط (`Listing.permitNumber`)، قرار الإلزام قرارك |
| 8 | هل المنصة **وسيط فقط** أم تستقبل مدفوعات نيابة عن مقدمي الخدمة؟ الثاني يغيّر المتطلبات التنظيمية جذريًا (قد يتطلب ترخيص مزود دفع/وسيط مالي) |
| 9 | لوحات المركبات: هل هناك قيود قانونية معروفة على "مزادات اللوحات" داخل المنصة يجب تطبيقها من البداية؟ |

## 3. تفضيلات تصميم

| # | السؤال | الافتراضي المُطبَّق فعليًا الآن |
|---|---|---|
| 10 | ألوان الهوية | أخضر زيتي غامق (`--brand-950 #16210f`) + رملي (`--sand-100 #f2ead9`) + ذهبي خافت (`--gold-500 #b8925a`)، بلا استنساخ لأي منصة قائمة |
| 11 | الخط العربي | IBM Plex Sans Arabic (مفتوح المصدر) عبر next/font |
| 12 | العربية أم الإنجليزية افتراضيًا | العربية (`ar`)، `dir="rtl"` افتراضي، تبديل واضح بالهيدر |
| 13 | اسم المشروع/الشعار | نص فقط حاليًا "UAE Services Hub" — قابل للتغيير من `lib/config/site.ts` (مصدر مركزي واحد)، لوحة إدارة لتعديله تُبنى بالمرحلة 4 |

## 4. تشغيلي

| # | السؤال |
|---|---|
| 14 | مواصفات السيرفر (RAM/CPU/قرص)؟ Qdrant + Postgres + MinIO + Next build تحتاج **8GB RAM كحد أدنى**، والمريح 16GB |
| 15 | Ollama بيشتغل على نفس السيرفر أو محليًا؟ يغيّر `EMBEDDINGS_BASE_URL` وشكل الشبكة |
| 16 | بيئة تنفيذ هذه الجلسة **لا تملك Docker daemon ولا وصول لسيرفرك** — الهجرة والاختبار تمّا محليًا عبر PostgreSQL مثبّت مباشرة. **يجب عليك تشغيل `docker compose up` فعليًا على سيرفرك والتحقق من Health Checks** قبل اعتبار الإنتاج جاهزًا — راجع `DEPLOYMENT.md` |

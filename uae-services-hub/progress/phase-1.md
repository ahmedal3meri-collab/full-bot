# تقرير المرحلة 1 — الأساس

التاريخ: 2026-07-27. بيئة التنفيذ: جلسة سحابية بلا Docker daemon — كل ما وُصف "مُختبَر" هنا اختُبِر فعليًا بالطرق البديلة الموضحة، وليس ادعاءً.

## ما تم إنجازه واختباره فعليًا

### قاعدة البيانات
- PostgreSQL 16 ثُبِّت وشُغِّل محليًا (`service postgresql start`) لأن Docker daemon غير متاح.
- `npx prisma migrate deploy` طُبِّق فعليًا — **42 جدولًا** أُنشئت (تحقّق بـ `\dt` عبر psql).
- ميغريشن يدوية ثانية أضافت GIN index + trigger PL/pgSQL لـ full-text search عربي/إنجليزي على `Listing`.
- `npx prisma seed` نُفِّذ بنجاح وأنتج:
  - 8 أدوار، 18 صلاحية (RBAC)
  - 7 إمارات، 8 مدن، 22 منطقة
  - 77 قسمًا/تصنيفًا (7 أقسام رئيسية + فروعها الكاملة حسب المواصفة)
  - خصائص ديناميكية فعلية لـ 3 فئات (سيارات، فلل/شقق، لوحات)
  - 4 باقات اشتراك
  - حساب Super Admin + مستخدمين وشركة وإعلانين وطلب خدمة وتقييم تجريبيين (معلَّمين بوضوح "تجريبي")
- تحقّق مباشر بـ `psql`: `SELECT` على `Listing` و`Category` أعاد البيانات الصحيحة.

### التصميم ولغة الواجهة
- Next.js 16.2.12 (App Router، Turbopack) + Tailwind v4 + next-intl 4.13.
- هوية بصرية: أخضر زيتي غامق + رملي + ذهبي خافت (tokens بـ `app/globals.css`)، خط IBM Plex Sans Arabic/Latin عبر next/font.
- RTL افتراضي (عربي) وLTR (إنجليزي) — `dir` يتغيّر فعليًا في `<html>`، تحقّقت بلقطتي شاشة كاملتين (عربي/إنجليزي) عبر Playwright.
- Dark/Light mode بـ `data-theme` + `localStorage`، سكربت inline لمنع الوميض.

### المصادقة
- Argon2id (memoryCost=19456) لكلمات المرور.
- جلسات مخزّنة بقاعدة البيانات (لا JWT) — قابلة للإلغاء الفوري.
- رحلة كاملة اختُبِرت آليًا عبر Playwright: تسجيل → تحقق ظهور زر الخروج → تسجيل خروج → تحقق زوال الجلسة → تسجيل دخول بنفس البيانات → نجاح. تحقّق مباشر بقاعدة البيانات أن صف `Session` أُنشئ ثم `revokedAt` امتلأ بعد الخروج.
- Rate limiting أولي (بالذاكرة، مذكور كقيد مؤقت بـ SECURITY.md).

### الصفحات
- الرئيسية: هيرو + بحث + 7 أقسام رئيسية + إعلانات مميزة + شركات موثّقة + "كيف تعمل المنصة" + دعوة تسجيل شركات — **كل المحتوى من قاعدة بيانات حقيقية**، لا mock.
- صفحة القسم: تعرض الفروع إن كان قسمًا أبًا، أو الإعلانات مع فلترة بالإمارة إن كان قسمًا فرعيًا (نتيجة حقيقية: "1 نتيجة" لسيارة Land Cruiser التجريبية).
- صفحة الإعلان: صور، سعر منسّق بالدرهم، خصائص ديناميكية (7 حقول ظهرت فعليًا للسيارة التجريبية)، بطاقة الشركة، أزرار اتصال/واتساب.
- `/api/health`: يستعلم PostgreSQL فعليًا، يرجع 200 مع `db:"up"`.

### Docker/Infra (مكتوب، غير مُشغَّل فعليًا)
- `docker-compose.yml` (dev) و`docker-compose.prod.yml` + `docker/web.Dockerfile` (multi-stage dev/build/runner)، `docker/worker.Dockerfile`، `docker/realtime.Dockerfile`، `docker/Caddyfile`.
- **لم تُشغَّل عبر `docker compose up` فعليًا** — بيئة الجلسة بلا Docker daemon. البديل: PostgreSQL وRedis ثُبِّتا وشُغِّلا محليًا مباشرة، والـ worker/realtime شُغِّلا بـ `tsx` مباشرة واتصلا فعليًا بـ Redis/PostgreSQL محليين (راجع أدناه). **يجب تشغيل `docker compose up` فعليًا على سيرفر حقيقي والتحقق من `docker compose ps` قبل اعتبار الإنتاج جاهزًا.**

### Worker وRealtime
- `worker/index.ts`: اتصل فعليًا بـ Redis (`PING` نجح) وPostgreSQL (`SELECT 1` نجح)، ونفّذ مهمة سويب إنهاء الإعلانات المنتهية.
- `realtime/index.ts`: خادم Socket.IO حقيقي، `/health` أعاد `200` فعليًا. غير آمن للإنتاج بعد (لا تحقق جلسة) — موثّق صراحة بـ SECURITY.md.

### البناء والاختبارات
```
npm run build     → ✓ نجح (Next.js standalone، بدون أخطاء TypeScript)
npx tsc --noEmit  → 0 أخطاء
npm run test:unit → 8/8 نجحت (Vitest)
npm run test:e2e  → 4/4 نجحت (Playwright، متصفح Chromium حقيقي)
```

## ما لم يُنجَز (بصراحة، حسب الخطة)

- نموذج إضافة إعلان (رفع صور MinIO، تحقق MIME)
- طلبات الخدمة/عروض الأسعار/الحجوزات كواجهة مستخدم (الجداول جاهزة بالمخطط)
- المحادثات الفعلية المرتبطة بجلسة مستخدم حقيقية (الـ Socket.IO server موجود لكن غير مربوط بـ auth)
- لوحة الإدارة بالكامل
- المساعد الذكي وRAG وQdrant
- الدفع (لا مزود مربوط، لا مفاتيح وهمية)
- تشغيل فعلي عبر Docker Compose على أي سيرفر
- اختبار استعادة فعلي للنسخ الاحتياطية

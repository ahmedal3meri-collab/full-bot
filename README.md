### 🎮 الألعاب
- `/dice` — رمي النرد
- `/flip` — رمي العملة
- `/rps` — حجر ورقة مقص
- `/trivia` — أسئلة ثقافية
- `/8ball` — الكرة السحرية
- `/slot` — ماكينة الحظ
- `/guess` — لعبة التخمين

### 🛠️ الأدوات
- `/calc` — حاسبة علمية
- `/weather` — الطقس
- `/translate` — ترجمة 20+ لغة
- `/qr` — إنشاء QR Code
- `/password` — توليد كلمة مرور آمنة
- `/hash` — MD5/SHA1/SHA256/SHA512
- `/encode` `/decode` — Base64
- `/uuid` — توليد UUID
- `/time` — الوقت في أي مدينة
- `/wiki` — بحث ويكيبيديا

### 📝 الملاحظات والتذكيرات
- نظام ملاحظات شخصي لكل مستخدم
- تذكيرات قابلة للضبط (ثواني، دقائق، ساعات، أيام)

### 👥 إدارة المجموعات
- رسائل ترحيب/وداع مخصصة
- Anti-flood لمنع السبام
- تثبيت/إلغاء تثبيت الرسائل

### 🎛️ لوحة الإدمن
- إحصائيات البوت
- بث رسائل لجميع المستخدمين
- حظر/رفع حظر المستخدمين
- إدارة المدراء

### 📱 Inline Mode
- `@bot calc 2+2`
- `@bot tr مرحبا`
- `@bot hash نص`
- `@bot joke`

## 🚀 التشغيل

```bash
# 1. نسخ ملف الإعدادات
cp .env.example .env

# 2. تعبئة القيم في .env
nano .env

# 3. تثبيت المتطلبات
pip install -r requirements.txt

# 4. تشغيل البوت
python bot.py
```

## ⚙️ الإعداد

1. أنشئ بوت من @BotFather واحصل على BOT_TOKEN
2. احصل على مفتاح Anthropic API من console.anthropic.com
3. (اختياري) احصل على OpenWeather API key للطقس الحقيقي
4. أضف معرفك في ADMIN_IDS
